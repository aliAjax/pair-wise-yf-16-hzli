# hxyfront-62004 滑雪板调校维护（雪板维护联动台）

面向滑雪板调校店的装备维护前端系统。预置底板损伤、刃角和打蜡状态，技师在同一工作台完成
「损伤登记 → P-Tex 固化 → 抛光打蜡 → 刃角联动 → 复检交付」全流程。全部数据仅保存在浏览器
localStorage，无后端。

## 联动规则

1. **未修损伤必须登记修补位置并确认固化**：损伤描述 + 修补位置必填；未固化时禁止抛光打蜡。
2. **新增打蜡必须选现有蜡批次**并填写克重。
3. **整单拒绝**：批次余量不足，或同类蜡被其他工单（待复检中）冻结时，打蜡请求被整体拒绝，
   工单、批次余量、损伤记录保持原样（校验全部通过后才原子写入）。
4. 打蜡成功即**占用批次余量并冻结同类蜡**，工单转待复检。
5. **打蜡后改动刃角**：工单保持/转待复检，批次占用保留。
6. **复检不通过退回重做**：状态回待维护、释放占用、解除同类蜡冻结、清除抛光标记，原打蜡记录
   标记“复检退回”并留痕；复检通过则完工，占用转为已耗。
7. 完工状态筛选、批次余量、客户历史维护记录实时同步。

## 预置数据

- ORD-106（完工，低温蜡已耗入账）、ORD-112（底板深划痕、未登记位置/未固化）
- ORD-118（机头损伤已固化待打蜡）、ORD-121（打蜡后改过刃角，待复检，批次占用中）
- 4 个蜡批次（低/中/高温蜡 + 一个小余量批次用于演示拒绝）

页面右上角「重置演示数据」可随时恢复预置数据。

